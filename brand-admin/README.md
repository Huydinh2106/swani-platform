# Web quản lý brand — chỗ dành sẵn

Thư mục này chưa có web app hoặc dependency. Task AI 5 sẽ khởi tạo React + Vite + TypeScript khi nhóm bắt đầu luồng quản trị; việc đó cần thống nhất package/lockfile và cách dùng chung contract trước.

Dùng chung màu, font và ngôn ngữ thiết kế từ docs/design-system.md. Component React Native và component DOM khác nhau; không import trực tiếp Button native vào Vite. Web dùng shadcn/ui hoặc bộ component web đã thống nhất, ánh xạ semantic token tương ứng.

Màn cần có: đăng nhập brand, thông tin/cửa hàng, nhập bài đăng, duyệt draft, danh sách sản phẩm, lịch sử đồng bộ. Đọc docs/backend-contract.md và docs/tasks/05-brand-backend.md.
